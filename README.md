# Euro Energy Data Pipeline

## Project Overview
This project collects, stores, and processes European energy data using PostgreSQL and Apache Airflow.

## Local Setup
1. Clone repository
2. Create `.env`
3. Run `docker compose up -d`
4. Open Airflow at http://localhost:8080

## Services
- PostgreSQL: localhost:5432
- Airflow: http://localhost:8080

## Database
Database name: euro_energy
